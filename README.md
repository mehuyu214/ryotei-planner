# Route Planner — 旅程プランナー

場所ごとに「何分いたいか（滞在時間）」と「この時間帯にいたい（希望時間帯）」を入れると、
希望のズレが最小で、移動＋待ち時間も最短になる最高効率の旅程を自動で提案します。

## 使い方

1. 出発地と行きたい場所を入力（先頭が出発地、最大25件）
2. 各場所に滞在時間（分）と、必要なら希望時間帯（開始〜終了）を入力
3. 出発時刻・移動手段（車／徒歩／自転車）を選び「最高効率の旅程を計算」
4. 地図に実経路と訪問順が描かれ、左パネルに到着・出発時刻つき旅程、区間ごとの距離・時間・料金（車は燃料代の概算）、希望どおり入ったか／何分ずれたかが表示されます

## 仕組み

- 地図: Leaflet + OpenStreetMap
- 地名検索: Nominatim、経路・所要時間: OSRM（APIキー不要）
- 最適化: 全地点間の所要時間行列から訪問順を組み、スケジュールをシミュレーションして
  「希望時間帯の違反（分）→ 移動＋待ち時間」の順で最小化（最近傍法＋局所探索）
- 各区間に Google マップで開くリンク付き

参考: [shinatacos/haruhi-map](https://github.com/shinatacos/haruhi-map) のUI構成（左パネル＋地図）を踏襲。
